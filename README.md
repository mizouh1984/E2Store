للتثبيت أو التحديث التلقائي المباشر على جهازك (Vu+, Novaler, Dreambox وغيرها)، انسخ الأمر التالي والصقه في برنامج **PuTTY** أو **Terminal**:

```bash
wget -q "--no-check-certificate" [https://raw.githubusercontent.com/mizouh1984/E2Store/main/installer.sh](https://raw.githubusercontent.com/mizouh1984/E2Store/main/installer.sh) -O - | /bin/sh
